# Dove modificare il prodotto

Questo indice elenca **solo responsabilità e file esistenti**. Aggiornalo quando viene introdotta, spostata o rimossa una funzione. La mappa delle fasi future è in `START_HERE.md`.

| Voglio cambiare… | Vai a… |
| --- | --- |
| La descrizione e il flusso del prodotto | `project-docs/PRODUCT_CONTEXT.md` |
| Le istruzioni per modificare il repository | `AGENTS.md` |
| Quali file locali Git deve ignorare | `.gitignore` |
| L'ordine delle fasi o lo stato del progetto | `project-docs/START_HERE.md` |
| I principi sui dati e sulla privacy | `project-docs/DATA_AND_PRIVACY.md` |
| Una decisione di prodotto già presa o aperta | `project-docs/PRODUCT_DECISIONS.md` |
| Questo indice | `project-docs/WHERE_TO_CHANGE_CODE.md` |

Quando nascerà il codice, aggiungi qui frasi concrete come «Voglio cambiare quali prodotti sono esclusi» e il file che ne è responsabile. Evita collegamenti a file non ancora creati.
